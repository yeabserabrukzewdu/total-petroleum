ክፍል ፩ - ሰነዶች እና ቅድመ ማራገፍ / Section 1 - Documentation & Pre-Unloading
1.1. ሰነዶች ቀርበዋል / Delivery documents presented?
1.2. ሰነዶቹ ከጣቢያዉ ጋር ይዛመዳሉ / Documents match delivery point?
1.3. የነዳጅ አይነት እና መጠን ተረጋግጧል / Product type and quantity confirmed?
1.4. የልኬት ሰንጠረዥ አለ / Gauge table available?
1.5. ለ 30 ደቂቃ / 30-minute wait observed?
ክፍል ፪ - የጣቢያ እና የነዳጅ ታንከር ዝግጁነት / Section 2 - Site & Underground Tank Readiness
2.1. ትክክለኛው ታንከር ተለይቷል / Correct receiving tank identified?
2.2. ታንከሩ በቂ ቦታ አለው / Sufficient ullage available?
2.3. የታንከሩ በቂ ቦታ በዲፕ ስቲክ ተለክቷል / Ullage verified by dipstick?
2.4. የታንከር መክፈቻዎች ዝግ ናቸው / Tank openings secured?
ክፍል ፫ - መኪና አቀማመጥ እና ኢነርጂ መቆጣጠር / Section 3 - Vehicle Positioning and Energy Isolation
3.1. መኪናው በተፈቀደ ቦታ ተቆሟል / Truck parked correctly?
3.2. ወደፊት ለመውጣት መንገድ ነፃ ነው / Forward emergency exit clear?
3.3. የእጅ ፍሬን ተይዟል / Parking brake applied?
3.4. የጎማ መቆሚያ /ታኮ/ ተቀምጧል / Wheel chocks installed?
3.5. ሞተር ጠፍቷል / Engine switched off?
3.6. የባትሪ ኃይል መቁረጫ ስዊች ተጥፍቷል / Battery cut-off switch off?
3.7. የጭስ ማውጫ ማፈኛ ተገጥሟል / Flame arrestor placed?
ክፍል ፬ - የደህንነት ምልክቶች እና መሣሪያዎች / Section 4 - Safety Signage and Equipment
4.1. "አታጭስ" ምልክት ተቀምጧል / No smoking sign displayed?
4.2. “ነዳጅ በማራገፍ ላይ” ሰሌዳ አለ / Fuel unloading sign posted?
4.3. ሞባይል ስልኮች ጠፍተዋል / Mobile phones switched off?
4.4. የደሀንነት ኮኖች ተቀምጠዋል / Safety cones in place?
4.5. የ ኤ.ቢ.ሲ. አይነት የእሳት ማጥፊያዎች አሉ 2 x 9 ኪ.ግ / ABC type fire extinguishers available, 2 x 9kg?
4.6. የእሉሚኒየም ባልዲ አለ / Aluminum bucket available?

ክፍል ፭ - ሰራተኞችና ከአደጋ መከላከያ መሣሪያዎች / Section 5 - Personnel and PPE
5.1. አሽከርካሪው የማራገፍ ደሀንነት ስልጠና አለው / Driver trained in unloading?
5.2. የማደያ / ደንበኛ ተወካይ የማራገፍ ደሀንነት ስልጠና አለው? / Station representative trained in unloading?
5.3. አሽከርካሪው PPE ለብሷል (ሄልሜት፣ መነጽር፣ ቱታ፣ ጓንት፣ ጫማ) / Driver wearing PPE (helmet, goggles, overall, gloves, safety shoes)?
5.4. የማደያ / ደንበኛ ተወካይ PPE ለብሷል (ሄልሜት፣ መነጽር፣ ቱታ፣ ጓንት፣ ጫማ) / Station representative wearing PPE?
ክፍል ፮ - ማራገፊያ ሆዝ፣ ማሳ እና ቴክኒካል ቁጥጥር / Section 6 - Hose, Grounding and Controls
6.1. ማሳ (ኤሌክትሪክ ወደ መሬት ማገናኛ) ተያይዟል / Grounding cable connected?
6.2. ማሳ ከሆዝ በፊት ተያይዟል / Grounding done before hose connection?
6.3. ሆዙ ጥራቱ ጥሩን የጠበቀ ነው / Hose in good condition?
6.4. ሆዙ ከመኪና ስር አያልፍም / Hose does not run under vehicle?
6.5. መደገፊያዎች ተዘርግተው ተቆልፈዋል / Double handrail deployed and locked?
6.6. የኤር ብሬክ ቫልቭ ሙሉ ጭነት ላይ ነው / Trailer brake valve set at full load?
ክፍል ፯ - የማራገፍ ሂደት ክትትል / Section 7 - Unloading Monitoring
7.1. በአንድ ጊዜ አንድ ነዳጅ ብቻ ይራገፋል / Unloading one product at a time?
7.2. አሽከርካሪው በአቅራቢያ ነው / Driver remains near the vehicle?
7.3. የማደያ / ደንበኛ ተወካይ በአቅራቢያ ነው / Station representative remains near the vehicle?
7.4. ማንጠባጠብ ወይም ፍሰስ አልታየም / No leaks or spills?
ክፍል ፰ - ከማራገፍ በኋላ / Section 8 - Post-Unloading
8.1. ሆዞች በትክክል ተለይተዋል / Hoses disconnected correctly?
8.2. ማሳ (ኤሌክትሪክ ወደ መሬት ማገናኛ) በመጨረሻ ተለይቷል / Grounding removed last?
8.3. የማራገፍ ቦታ ተጠርጎ ተነጻ / Unloading area cleaned?
8.4. ሰነዶች ተፈርመዋል / Documents signed?
